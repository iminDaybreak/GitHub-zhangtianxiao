# Guide: Create your first GitHub repository
## Prerequisites
1. A valid GitHub account (registered and logged in)
2. Internet access
3. A web browser (Chrome, Edge, Firefox etc.)

## Steps
1. Go to https://github.com and sign in to your account.
2. Click the "+" icon at the top-right corner, then select "New repository".
3. Type a repository name (no space), choose Public or Private. Check "Add a README file".
4. Click the green "Create repository" button.
5. Open the README file and click the pencil icon to edit your content.

## Result Check
✅ Check 1: You can see your repository name on your GitHub profile page.
✅ Check 2: The README.md file exists and you can edit it.
✅ Check 3: The repository page loads without error.
# Documentation Edit Assignment
## Six Style Rules
### Rule 1: Use direct active verbs, avoid noun-heavy phrases
Before: Carry out the removal of the cover and subsequently inspect the cable.
After:
1. Remove the cover.
2. Inspect the cable.

### Rule 2: Remove informal subjective language; keep tone neutral and factual
Before: It is super easy to update your intro file.
After: Update the introduction file following these steps.

### Rule 3: Split one multi-action sentence into separate steps for each action
Before: Open it and do the necessary editing.
After:
1. Open the introduction file.
2. Edit the required content.

### Rule 4: Replace vague words such as “necessary”, “somebody” with specific terms
Before: If you cannot edit, ask somebody.
After: If you cannot edit the file, contact the project maintainer.

### Rule 5: State the exact action to save and submit, avoid ambiguous “save with Publish”
Before: Save it with Publish.
After: Click **Publish** to save and submit your changes.

### Rule 6: Specify the verification target for post-action checks
Before: Check it afterwards.
After: Review the published README to confirm your edits appear correctly.
